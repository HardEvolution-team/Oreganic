# Oreganic Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Oreganic** by Chris 'Crystic' Edwicker.

- Original: https://crystic.github.io/oreganic.html
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.25.0+

This port contains **no original assets**. Put your own copy of the original jar (`oreganic_mod_1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
